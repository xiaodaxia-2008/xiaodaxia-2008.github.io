# Windows Terminal 分屏与调整常用快捷键总结

本指南总结了 Windows Terminal 中处理窗格（Panes）的核心操作。

## 1. 窗口分屏 (Split Panes)
将当前的标签页分割为多个独立运行的窗口。

| 操作项目 | 默认快捷键 | 说明 |
| :--- | :--- | :--- |
| 垂直分屏 | Alt + Shift + + | 将窗口左右平分 (增加一个垂直边界) |
| 水平分屏 | Alt + Shift + - | 将窗口上下平分 (增加一个水平边界) |
| 自动分屏 | Alt + Shift + D | 自动根据长宽比选择最优方向分屏 |

## 2. 调整窗格大小 (Resizing Panes)
选中目标窗格后，通过以下组合键微调边界位置。

| 操作项目 | 默认快捷键 |
| :--- | :--- |
| 向左缩放 | Alt + Shift + 左箭头 |
| 向右缩放 | Alt + Shift + 右箭头 |
| 向上缩放 | Alt + Shift + 上箭头 |
| 向下缩放 | Alt + Shift + 下箭头 |

提示：也可以直接用鼠标拖动窗格之间的分割线进行调整。

## 3. 导航与管理 (Navigation & Management)
在多个分屏之间快速切换或关闭。

| 操作项目  | 默认快捷键            | 说明                                    |
| :---- | :--------------- | :------------------------------------ |
| 切换焦点  | Alt + 方向键        | 将光标移动到相邻的窗格                           |
| 关闭窗格  | Ctrl + Shift + W | 关闭当前选中的分屏                             |
| 最大化窗格 | (需手动绑定)          | 临时全屏显示当前窗格 ( 切换窗格缩放 Toggle Pane Zoom) |

## 4. 进阶 Tips
- 同目录分屏：在点击分屏按钮或快捷键时，配合 Alt 键通常可以在当前工作目录下打开新窗格。
- 修改步长：如果觉得调整大小太慢，可以在 settings.json 中搜索 resizePane 并修改其 step 参数。
